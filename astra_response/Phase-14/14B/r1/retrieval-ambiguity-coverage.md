# Retrieval, ambiguity and coverage

The baseline uses descriptions, not pixels, for retrieval. Up to twelve complete
text terms independently query existing set-name search and the new bounded
minifigure-name helper under one accepted catalog snapshot. The union includes
catalog candidates lacking photographs. Names/features use exact token overlap:
name=3, source features=2, exact name phrase bonus=6. Ties use exact
kind/namespace/identifier; identifiers do not contribute to scores.

Each term/type returns at most 100 rows; a saturated result marks coverage truncated.
The shortlist defaults to eight (maximum twelve). No-match means no match in this
queried coverage. Scores are not confidence, visual compatibility or identity proof.
